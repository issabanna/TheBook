# Shared $7.99 checkout for available books

Enable the thirteen previously unavailable $7.99 books with book-specific Buy buttons on Testing and production. They use the existing Life Secrets hosted PayPal link, CS8XK9B6XLU64. Life Secrets keeps its $7.99 price and uses the same selected-book confirmation flow. The Art of Attention ($8.99), Lead Without the Noise ($8.99), and Man and People ($9.99) retain their existing hosted links and prices, as explicitly requested. Social Mirror's separate $4 checkout is unchanged. Complete books, covers, three-page samples, reader reviews and the 10/7 catalogue are unchanged.

A short OPortals confirmation page names the selected title, price and PDF format. It explains before payment that PayPal may label the shared item Life Secrets. Continuing records an order in D1, issues signed book-selection proof and remembers it in the checkout tab before opening PayPal. Shared checkout starts on oportals.com so its browser context matches the merchant return origin. An essential signed HttpOnly cookie can suggest the selected title if tab context is lost. Checkout and receipt pages preserve same-origin POST headers.

On return, the existing server-side PayPal PDT verification still checks completed status, transaction ID, exact USD amount and the configured seller. A paid transaction is atomically allocated to one book, with unique transaction and order constraints. Tokens name that allocated book. Download requests reverify PayPal and the allocation; a transaction cannot be retargeted, a token cannot unlock another book, and refunds stop delivery. Historic Life Secrets receipts remain valid for Life Secrets and cannot be used to claim a newly selected title. A fixed runtime activation date distinguishes new shared payments from legacy receipts; preserve that date after launch.

If the original tab is unavailable, a newly verified unallocated $7.99 payment offers the fourteen equal-priced book choices. The payer confirms the purchased title once, then the same immutable allocation applies. Higher-priced books cannot be selected with this payment. This covers different-browser PayPal returns without silently substituting Life Secrets. IPN sends a generic verification receipt until the book is allocated, then uses the allocated title and matching PDF. No payer email is accepted from browser fields. Optional receipt-email failure does not prevent an already verified download.

Schema-only migration 0009 adds book_checkout_orders and book_payment_allocations plus an order lookup index. Existing migration SQL and journal values are untouched. Orders store a pseudonymous signed browser-session ID, book and timestamps; allocations retain the verified transaction/book association. No payer email or raw IP is stored in these tables. Checkout creation has a temporary hashed-IP/session limit. Public routes do not expose either table. No existing customer data is backfilled or modified.
